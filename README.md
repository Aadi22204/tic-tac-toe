# 🎮 Tic-Tac-Toe | Python + Streamlit

A modern interactive Tic-Tac-Toe game built using Python, NumPy and Streamlit.

The project demonstrates game logic, NumPy array operations, Streamlit session state, input validation and UI development.

## ✨ Features

- 🎮 Interactive Tic-Tac-Toe gameplay
- ❌ Player X
- ⭕ Player O
- 🏆 Automatic winner detection
- 🤝 Draw detection
- 📊 Scoreboard
- 🔄 New Game option
- 🗑️ Reset Score option
- ⚠️ Occupied-cell validation
- 📱 Streamlit-based interface
- 🧩 Modular game logic
